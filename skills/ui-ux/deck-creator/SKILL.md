# Deck Creator

## Overview

This Skill supports crafting the narrative arc, structure, and visual storytelling of presentation decks.

## Purpose

Help presenters communicate ideas persuasively through a clear narrative and visual hierarchy.

## When to Use

- Planning the narrative structure for an important presentation
- Reviewing an existing deck for clarity and persuasive flow

## When NOT to Use

- For purely mechanical slide generation with no narrative design needs
- For Word document creation (use the word-creation skill)

## Prerequisites

- A clear understanding of the audience and desired outcome
- The key messages or data points to be communicated

## Workflow

1. Define the core message and desired audience takeaway
2. Structure the narrative arc across the deck's sections
3. Refine visuals and pacing to reinforce the narrative

## Best Practices

- Open with the core message before diving into supporting detail
- Use visuals to support the narrative rather than repeat spoken content

## Common Pitfalls

- Burying the key message deep in the deck instead of leading with it
- Including too much supporting detail that dilutes the core narrative
