# PPTX Generation

## Overview

This Skill supports generating PowerPoint presentations programmatically from structured content and templates.

## Purpose

Produce consistent, on-brand PowerPoint decks without manual slide-by-slide formatting.

## When to Use

- Generating a PowerPoint deck programmatically from data or content
- Automating recurring, templated presentation creation

## When NOT to Use

- For one-off, highly custom decks better designed manually
- For Word document generation (use the word-creation skill)

## Prerequisites

- A defined slide template and brand style guide
- Structured source content to populate the slides

## Workflow

1. Map the source content to a slide-by-slide outline
2. Generate slides using the approved template and layouts
3. Review the deck for layout, readability, and brand consistency

## Best Practices

- Limit each slide to one key message or idea
- Reuse a consistent master slide and layout set

## Common Pitfalls

- Overcrowding slides with too much text
- Inconsistent fonts, colors, or spacing across slides
