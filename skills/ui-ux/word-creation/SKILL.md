# Word Creation

## Overview

This Skill supports generating professional, well-formatted Word documents from outlines or templates.

## Purpose

Produce consistent, polished Word documents that follow the organization's formatting standards.

## When to Use

- Generating reports, proposals, or contracts as Word documents
- Converting structured content into a formatted Word template

## When NOT to Use

- For presentation slide generation (use the deck-creator skill)
- For simple plain-text notes that don't need rich formatting

## Prerequisites

- A defined content outline or source material
- Access to the organization's Word template and style guide, if applicable

## Workflow

1. Organize the content into a clear heading structure
2. Apply consistent styles for headings, body text, and lists
3. Review the generated document for formatting and accuracy

## Best Practices

- Use built-in heading styles rather than manual bold and font sizing
- Keep a consistent template for recurring document types

## Common Pitfalls

- Manually formatting text instead of using paragraph and character styles
- Producing inconsistent formatting across similar document sections
